# SurvivorQoL

Quality-of-life modules for **Azeroth Survivors** (WoW 1.12). Turn each one on or off in the settings window.

Open the settings with **/qol** or the gear button on the minimap.

## Modules

- **Nameplates**: right-click turning works when the mouse is over a nameplate. Hold Shift to click nameplates again.
- **Stats panel**: your main stats during a run. When a pick changes a stat, the difference shows for a few seconds.
- **Cursor**: six styles to find your mouse on a crowded screen (Halo, Reticle, Crosshair, Spotlight, Sonar, Laser lines), plus a trail. Shake the mouse to make it big for a moment.

## Moving frames

On the General page, click **Move frames**, drag the frames where you want them, then click **Done**. Settings and positions are saved for your account, so every character shares them.

## Commands

- `/qol` opens or closes the settings window.
- `/qol move` starts Move frames.
- `/qol stats all` lists every stat the game sends.

## Install

Install it with SurvivorsForge, or copy the `SurvivorQoL` folder into `benilla-config\AddOns`.
